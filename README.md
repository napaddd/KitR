#  Overview
Open the Kit Config and browse through the categories to turn ON or OFF certain PVP features.

## ❗ KitR is new
You can **suggest new features** or **report bugs** in my discord server : https://discord.gg/CW5CA6t6Zu

Downloading the project for version before **1.21.11** will give you the V1 of the project, which is "_Equipment Manager_" and has a lot less features.

## ❔ How to use
To open the config screen, open the Pause Menu by pressing **ESC** and click on **Kit Config**. 

Running **/function kit:config** in the chat is also an option. 

These two ways can only be accessed if you have OP permissions.

## ⚙️ Features
In the Kit Config, there are 5 categories : 

_(See **Gallery** for more details)_
### ![Weapons Icon](https://cdn.modrinth.com/data/cached_images/69b0fbb2b92ffdde72823bd0ea561582e9323888.png) Weapons, tools and armor
Toggle every single Netherite piece, the netherite upgrade and has 2 sub-categories : Mace Options and Explosives Options
### ![Utilites Icon](https://cdn.modrinth.com/data/cached_images/28c6b3288d065f0ea1fbb696d647342dd0517ae2.gif) Utilities
Toggle certain PVP utilities like Totems, Elytra, Cobwebs and others and put a cap on how many of a certain item can be held in the inventory (item caps might work in an annoying way). This category also has a sub-category : Ender Pearl Options
### ![Potions Icon](https://cdn.modrinth.com/data/cached_images/640a5be5c62b300b1c84e558aaa3124aa409a907.png) Potions
Currently only has **Longer Strength II** and **Longer Speed II**
### ![SMP Features Icon](https://cdn.modrinth.com/data/cached_images/82b63acccfece809780f0c393a6ce1568e91f259.png) Custom SMP Features
Currently only has **Bliss Dragon Egg** which puts the Dragon Egg holder at 20 hearts
### ![Misc Icon](https://cdn.modrinth.com/data/cached_images/61edf342c79bcc1998d7de5770b775e99865877d.png) Miscellaneous
Options for the config itself

<summary>Installation</summary>
  
### Server Installation (Datapack)
  
1. Go in the main server file
  
2. Open _world_ -> _datapacks_

3. Upload the datapack in the _datapacks_ folder

### World Installation (Datapack)

1. Press Win + R and enter %appdata%

2. Open _.minecraft_ -> _saves_ -> _<world name>_ -> datapacks

3. Upload the datapack in the _datapacks_ folder

(Note that if you are using a launcher like Modrinth App or Prism Launcher, you'll need to go on your instance on the launcher and click on _Open Folder_.)

### Server Installation (Mod)

1. Go in the main server file

2. Open _mods_

3. Upload the mod in the _mods_ folder
